## Pentesting: all-purpose

- [Hacktricks](https://book.hacktricks.wiki/en/index.html) — Widely used pentesting tips and tricks, covering a wide range of topics from web application security to network pentesting and more.
- [The-hacker-recipes](https://www.thehacker.recipes/) — A collection of recipes for various hacking techniques and tools. Especially AD pentesting steps are explained in great detail here
- [Ippsec.rocks](https://ippsec.rocks/) — A collection of video resources related to penetration testing, including detailed explanations of various techniques and tools.
- [0xdf writeups](https://0xdf.gitlab.io/search) — A collection of write-ups and walkthroughs for various Capture The Flag (CTF) challenges and penetration testing exercises.
- [exploit-db](https://www.exploit-db.com/) — A database of exploits and vulnerabilities
- [Sploitus](https://sploitus.com/) — A search engine for exploits and vulnerabilities
- [emanuel solis cheat-sheet](https://www.emmanuelsolis.com/oscp.html) — comprehensive cheat-sheets covering a wide-range of topics relevant to penetration testing

## Pentesting: privilege escalation

- [Gtfobins (Linux)](https://gtfobins.github.io/) — A collection of Unix binaries that can be exploited by an attacker to bypass local security restrictions.
- [Lolbas (Windows)](https://lolbas-project.github.io/) — A collection of Windows binaries that can be exploited by an attacker to bypass local security restrictions.
- [LinPEAS](https://github.com/peass-ng/PEASS-ng/releases/) — A set of scripts that searches for possible paths to escalate privileges on Linux systems.
- [WinPEAS](https://github.com/peass-ng/PEASS-ng/releases/) — A set of scripts that searches for possible paths to escalate privileges on Windows systems.
- [LinEnum](https://github.com/rebootuser/LinEnum) — A script that performs a comprehensive enumeration of a Linux system to find potential privilege escalation vectors.
- [Kernel exploits Windows](https://github.com/SecWiki/windows-kernel-exploits) — A collection of known Windows kernel exploits that can be used to escalate privileges on a vulnerable system.
- [Kernel exploits Linux](https://github.com/SecWiki/linux-kernel-exploits) — A collection of known Linux kernel exploits that can be used to escalate privileges on a vulnerable system.
- [pspy32 / pspy64](https://github.com/DominicBreuker/pspy) — A tool that allows you to monitor processes on a Linux system without requiring root privileges.

## Pentesting: useful tools

- [Revshells](https://www.revshells.com/) — A collection of shell payloads for various programming languages and platforms.
- [Tldr](https://tldr.sh/) — A easy manual for command line tools, providing simplified and community-driven examples.
- [Cyberchef](https://gchq.github.io/CyberChef/) — A web-based tool for performing various encoding, decoding, and data manipulation tasks.
- [Crackstation (hashes)](https://crackstation.net/) — A free online service for cracking password hashes using a large database of pre-computed hashes.
- [Static SSH server](https://github.com/Fahrj/reverse-ssh) — A simple static SSH server that can be used for reverse SSH connections, useful for establishing a persistent connection to a remote system.
- [Curl converter](https://curlconverter.com/) — A tool that converts curl commands into code snippets in various programming languages.
- [Weakpass](https://weakpass.com/) — A database of weak passwords and password patterns, useful for password cracking and security assessments.
- [Sysreptor](https://offsec.sysreptor.com/offsec/signup) — A web-based reporting tool for penetration testers to create professional reports quickly and efficiently.
- [DefaultCreds-cheat-sheet](https://github.com/ihebski/DefaultCreds-cheat-sheet) — cheat sheet for a select number of default credentials. Gives the possibility to search for the credentials.
- [Deobfuscate javascript](https://deobfuscate.io) — Deobfuscate javascript code to more human-readable code

## Web pentest: resources

- [CSP bypass](https://cspbypass.com) — A collection of techniques and payloads for bypassing Content Security Policy (CSP) in web applications.

## OSINT: resources

- [Google dork - prebuilds](https://dorksearch.com/) — A collection of pre-built Google dorks for various purposes.
- [Google dork - hacking DB](https://www.exploit-db.com/google-hacking-database) — A database of Google dorks specifically related to security vulnerabilities and exploits.
- [Shodan](https://www.shodan.io/) — A search engine for Internet-connected devices, allowing users to find specific devices and services based on various criteria.
- [ransomware live](https://www.ransomware.live) — A live feed of ransomware attacks and incidents, providing information about the affected organizations, attack vectors, and other relevant details.
